# Cornerstone Forge v0.1.0-alpha (Pre-release)

## Main features

Cornerstone Forge provides PhotonForge-ready implementations of Cornerstone silicon photonics PDKs in a single Python workspace.  
This pre-release focuses on delivering a usable **SOI 220 nm passive PDK** with a parametric technology definition, process-aware layers/media/ports, and a broad preloaded component catalogue (O-band and C-band), while also introducing an **SOI 220 nm active PDK package scaffold** for upcoming active-device support.  
The repository also includes developer tooling (tests, linting, formatting, pre-commit), CI workflows, and MkDocs-based documentation to support contribution and adoption.

## Features implemented (chronological)

1. **2026-09-22 — Initial project baseline (PR #3)**
   - Workspace structure with multi-package layout for `csforge-si_220nm_passive` and `csforge-si_220nm_active`.
   - Passive SOI 220 nm technology stack implementation (materials, layers, extrusions, ports, utilities, and technology factory).
   - Passive component catalogue integration backed by GDS/YAML assets and S-parameter data across O-band/C-band plus band-agnostic cells.
   - Public package APIs for component discovery and instantiation.
   - Initial test suite for package, technology, components, and models.
   - Documentation setup (root docs, user/developer guides, passive PDK reference) with MkDocs configuration.
   - Contributor/developer tooling and CI workflows (`pytest`, Ruff/pre-commit, docs workflow).

2. **2026-09-22 — Passive PDK example design notebook (PR #7)**
   - Added `csforge-si_220nm_passive/notebooks/example-design.ipynb` as an initial practical design/example notebook for the passive PDK.
