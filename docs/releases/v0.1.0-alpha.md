# Cornerstone Forge v0.1.0-alpha (Pre-release)

## Main features

Cornerstone Forge provides PhotonForge-ready implementations of Cornerstone silicon photonics PDKs.

### uv workspace + packages for each PDKs repo organisation

The repository is structured as a uv workspace with separate Python packages aligned to the PDK organisation: `csforge-si_220nm_passive` and `csforge-si_220nm_active`.  
This enables shared tooling and dependency management at the root while keeping each PDK package independently versionable and maintainable.

### GitHub Pages documentation website

Documentation is built with MkDocs and organized for both users and developers, with a dedicated passive-PDK reference section.  
The project includes a documentation workflow intended for publishing a GitHub Pages documentation website.
